## 东方美学系列

灵感源自中国传统美学与诗词意境，适合文化、材料、环境科学等领域的图表，具有独特的人文质感。

### 烟雨釉色 (misty-glaze)

| 序号 | HEX | RGB | 用途 |
|------|-----|-----|------|
| 1 | `#f0f7f7` | 240,247,247 | 背景/填充色 |
| 2 | `#b2d8dc` | 178,216,220 | 主数据色 |
| 3 | `#b0d9dd` | 176,217,221 | 次数据色 |
| 4 | `#b0dbdd` | 176,219,221 | 第三数据色 |

- **风格**：青瓷釉色，清淡雅致，低饱和青绿色调
- **适用**：环境科学、材料表征、生物医学可视化
- **注意**：色差异较小，适合展示渐变层次，不适合需要强对比的多类别分组

## 连续色板（Sequential）

用于表示数值大小渐变的连续数据，如热图、等高线图、密度图。

### 蓝青渐变 (sequential-blue-teal)

```
#f7fbff → #deebf7 → #c6dbef → #9ecae1 → #6baed6 → #4292c6 → #2171b5 → #08519c → #08306b
```

- **适用**：温度分布、浓度场、强度图
- **特点**：从浅蓝到深蓝，经典科学可视化配色

### 温热渐变 (sequential-warm)

```
#fff5f0 → #fee0d2 → #fcbba1 → #fc9272 → #fb6a4a → #ef3b2c → #cb181d → #99000d → #67000d
```

- **适用**：热成像、应力分布、概率密度
- **特点**：从米白到深红，暖色调能量感

### 翠绿渐变 (sequential-forest)

```
#f7fcf5 → #e5f5e0 → #c7e9c0 → #a1d99b → #74c476 → #41ab5d → #238b45 → #006d2c → #00441b
```

- **适用**：生物量、生态指标、生长曲线
- **特点**：从浅绿到深绿，自然系

### 紫雾渐变 (sequential-purple)

```
#fcfbfd → #efedf5 → #dadaeb → #bcbddc → #9e9ac8 → #807dba → #6a51a3 → #54278f → #3f007d
```

- **适用**：光谱数据、紫外-可见吸收曲线、浓度梯度
- **特点**：从淡紫到深紫，优雅专业

## 发散色板（Diverging）

用于表示偏离中心值的双向数据，如正负偏差、盈亏、异常值。

### 红蓝发散 (diverging-red-blue)

```
#b2182b → #d6604d → #f4a582 → #fddbc7 → #f7f7f7 → #d1e5f0 → #92c5de → #4393c3 → #2166ac
```

- **中点**：`#f7f7f7`（中性灰）
- **适用**：差异分析、误差分布、相对变化率
- **特点**：经典 RdBu 反转，红色表示正向/高值，蓝色表示负向/低值

### 棕绿发散 (diverging-brown-green)

```
#8c510a → #bf812d → #dfc27d → #f6e8c3 → #f5f5f5 → #c7eae5 → #80cdc1 → #35978f → #01665e
```

- **中点**：`#f5f5f5`
- **适用**：干湿对比、正负效应、阴阳两极数据
- **特点**：Brown-Green 配色，学术感强

### 紫橙发散 (diverging-purple-orange)

```
#542788 → #998ec3 → #d8daeb → #f2f0f7 → #f7f7f7 → #fee0b6 → #fdb863 → #e08214 → #b35806
```

- **中点**：`#f7f7f7`
- **适用**：聚类分析、差异基因表达、相关性热图
- **特点**：Purple-Orange 对比鲜明

## 配色选择速查表

| 图表类型 | 推荐色板 | 色数 | 理由 |
|----------|----------|------|------|
| 分组柱状图（≤8组） | Nature 经典 / Okabe-Ito | 6-8 | 类别区分度高 |
| 折线图多系列（≤6条） | Science 简约 / 期刊投稿标准 | 4-6 | 线条清晰可辨 |
| 散点图聚类 | Nature 经典 | 3-5 | 突出簇间差异 |
| 热图（连续数据） | 蓝青渐变 / 翠绿渐变 | 9+ | 平滑色阶过渡 |
| 热图（差异数据） | 红蓝发散 / 紫橙发散 | 9 | 明确正负方向 |
| 流程图/示意图 | 东方美学系列 | 3-4 | 风格统一雅致 |
| 强调重点数据 | 三分缠绵 | 1-2 | 深红突出醒目 |
| 出版投稿通用 | Okabe-Ito 色盲安全 | 6-8 | 审稿友好，打印友好 |
